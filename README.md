
# Licensed Software Installation Request Management

## Project Overview
This project is developed using the ServiceNow platform to manage employee requests for licensed software installation through the Service Catalog.

It helps employees submit software installation requests and enables IT teams to manage approvals, assign installation tasks, and track request progress.

## Objectives
- Simplify software installation requests.
- Automate the approval process.
- Manage software license requirements.
- Improve IT service management.
- Track installation request status.

## Technologies Used
- ServiceNow
- Service Catalog
- Flow Designer
- JavaScript
- Approval Management
- Notifications

## Key Features
1. Employee Software Request
2. Software Selection
3. Manager Approval
4. IT Team Task Assignment
5. Installation Tracking
6. Request Status Updates

## Project Workflow

Employee → Submit Request → Approval → IT Team Assignment → Software Installation → Request Closure

## Benefits
- Centralized software request management.
- Faster approval processing.
- Better license management.
- Reduced manual work.
- Improved transparency.
